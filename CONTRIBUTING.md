# Contribuciones a everything-claude-code

Muchas gracias por dedicar tu tiempo a leer este documento. Significa muchísimo para nosotros. **everything-claude-code** es un proyecto integrado en el ecosistema de Megasoft, y el hecho de que estés aquí considerando contribuir al proyecto es algo que de verdad valoramos profundamente y no damos por sentado.

Como es un proyecto de mantenimiento personal e individual (a cargo de Andrés Sánchez), las revisiones de contribuciones y la resolución de Issues se realizarán de manera voluntaria en nuestro tiempo libre. No hay un tiempo de respuesta fijo garantizado, pero intentaremos revisar cada aportación con el mayor cariño posible.

## Cómo empezar a colaborar

1. **Haz un Fork:** Clona el repositorio en tu propia cuenta de Forgejo.
2. **Crea una Rama Descriptiva:** Usa nombres claros y estructurados, preferiblemente siguiendo Git Flow (ej: `feature/mi-nueva-funcion` o `bugfix/resolver-error`).
3. **Desarrolla de forma Limpia:** Sigue el estilo de código existente del proyecto.
4. **Commits Convencionales:** Tus mensajes de commit deben seguir la especificación de [Conventional Commits](https://www.conventionalcommits.org/es/v1.0.0/).
5. **Abre un Pull Request:** Envía tu propuesta a la rama `main`. Será revisada por el mantenedor antes de integrarse.

## Estándares de Código y Calidad (Definition of Done)

Para que una contribución sea aprobada y fusionada, debe cumplir con los siguientes requisitos mínimos:
* **Sin AI Slop:** El código debe ser limpio, eficiente y estar libre de redundancias o placeholders innecesarios generados por IA.
* **Calidad y Validación:** El código debe pasar los tests y validaciones locales definidas en `.no-mistakes.yaml`.
